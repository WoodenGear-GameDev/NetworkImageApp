# NetworkImageApp (Avalonia UI)

Кроссплатформенное решение на базе **.NET** и **Avalonia UI**, состоящее из двух приложений: **Сервера (`ServerApp`)** с графическим отображением контента и интерактивной консолью логов, а также **Клиента (`Controller`)** для удаленного управления и отправки управляющих сигналов.

---

## 🏗 Архитектура репозитория

Проект разделен на две независимые части:

1. **ServerApp** — серверная часть с графическим интерфейсом (динамическое отображение изображения и консоль мониторинга).
2. **Controller (ClientApp)** — клиентское приложение для подключения к серверу и отправки команд.

## 🖥 1. Серверное приложение (`ServerApp`)

Сервер принимает входящие подключения по TCP, удерживает постоянное соединение с активным клиентом в асинхронном цикле чтения и обрабатывает управляющие команды.

### Основные элементы интерфейса:
* **Панель подключения:** Поля для отображения локального IP-адреса, ввода порта и кнопка **«Open»/«Close»** для запуска/отключения прослушивания сокета.
* **Область отображения:** Центральный блок с изображением, которое изменяется при получении команды `CHANGE` от клиента.
* **Интерактивная консоль (внизу):**
  * Отображает логи работы сервера и статусы подключений.
  * Реализована автопрокрутка к новым сообщениям.
  * Оснащена кнопкой очистки логов (иконка корзины).

### Сетевые особенности:
* Поддерживает **постоянное соединение**: поток чтения не закрывается после первого сообщения, а работает в цикле `while` с использованием `Stream.ReadAsync`.
* Корректная обработка отмен через `CancellationTokenSource` и принудительный обрыв сокетов при остановке сервера.

## 🎮 2. Клиентское приложение (`Controller`)

Клиентское приложение представляет собой панель управления в темной стилизации, предназначенную для подключения к серверу и отправки команды `CHANGE`.

### Основные элементы интерфейса:
* **Поля ввода:** Ввод IP-адреса и сетевого порта целевого сервера.
* **Панель управления (Кнопки):**
  * **«Подключиться»** — инициализация TCP-соединения с сервером.
  * **«Отправить»** — передача команды `CHANGE` для изменения изображения на сервере.
  * **«Отключиться»** — штатное завершение сеанса связи.

## 🚀 Сборка и запуск

Для запуска каждого из проектов убедитесь, что у вас установлен **.NET SDK** (версия 8.0 или выше).

### Запуск сервера:
```bash
cd ServerApp
dotnet run
```

### Запуск клиента:
```bash
cd ClientApp
dotnet run
```

## 🛠 Технологический стек
* **Язык программирования:** C# (.NET)
* **UI-фреймворк:** Avalonia UI
* **Сетевое взаимодействие:** `TcpListener`, `TcpClient`, `NetworkStream`, асинхронные потоки ввода-вывода (`async/await`)
